# 🤖 Telegram AI Support Bot

Production-ready Telegram support bot with PostgreSQL, FSM workflows, admin panel and Docker support.

---

# ✨ Features

* 🤖 User support requests
* 📩 Admin notification system
* 📊 Admin statistics
* 📚 Requests history
* ⚡ FSM support workflow
* 🗄 PostgreSQL database
* 🚀 Railway deployment
* 🐳 Docker support
* 🔐 Environment variables

---

# 🔐 Admin Panel

Available commands:

* `/admin` — admin panel
* `/requests` — requests history

Admin features:

* 📊 Statistics
* 📩 Requests management
* 📚 Support history

---

# 🛠 Tech Stack

* Python 3.13
* Aiogram 3
* PostgreSQL
* Railway
* Docker
* GitHub

---

# 🧠 Architecture

* FSM (Finite State Machine)
* PostgreSQL persistence
* Modular handlers
* Reply keyboards
* Environment variables

---

# 🚀 Deployment

The bot is fully deployable on Railway with PostgreSQL support.

---

# 🐳 Docker

Run locally with Docker:

```bash
docker build -t ai-support-bot .
docker run ai-support-bot
```
